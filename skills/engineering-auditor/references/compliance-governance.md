# Compliance and Governance Audit

Inspect technical evidence related to:

- Data classification, PII handling, pseudonymization, anonymization, and production-data use.
- Least privilege, environment separation, ownership, approvals, and change controls.
- Retention, deletion, lineage, audit trails, reconciliation, and governance metadata.
- Data contracts, traceability, logging, documented responsibilities, and policy enforcement.

Use precise evidence language:

- `Technical control present` when implementation evidence exists.
- `Technical control absent` when the repository should contain the control and clearly does not.
- `Evidence not found in repository` when absence may reflect an external control.
- `Requires organizational validation` for process, policy, legal, and operational claims.
- `Potential compliance implication` for a technically supported risk without asserting legal status.

Never conclude that a system is GDPR, NIS2, ISO 27001, SOC 2, or otherwise legally compliant from repository inspection. Connect findings to technical controls and identify the external verification required.
